# Markdown voor macOS — updates

Dit is het openbare updatekanaal voor de persoonlijke Markdown-app.

De app en het updateoverzicht worden digitaal ondertekend. Markdown controleert de handtekening voordat een update wordt gebruikt. Automatisch installeren staat uit; nieuwe versies worden eerst aangeboden.

- Downloads: [Releases](https://github.com/tijmendus/markdown-macos-updates/releases).
- Updateoverzicht: `https://raw.githubusercontent.com/tijmendus/markdown-macos-updates/main/appcast.xml`.
- Build: Apple Silicon, macOS 14 of nieuwer.

Deze persoonlijke build is lokaal ondertekend, zonder Apple Developer ID of notarisering. Dit kanaal bevat alleen apppakketten en versie-informatie. Notities, privégegevens, ontwikkelbroncode en de privésleutel worden hier niet geplaatst.

Een app-update vervangt de app. De gekozen notitiemap en voorkeuren blijven afzonderlijk op de Mac staan.
